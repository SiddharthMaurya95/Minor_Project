1.  Abstract 
Medical
 
image
 
classification
 
is
 
an
 
important
 
application
 
of
 
deep
 
learning
 
in
 
healthcare.
 
Convolutional
 
Neural
 
Networks
 
(CNNs)
 
have
 
shown
 
strong
 
performance
 
in
 
learning
 
visual
 
patterns
 
from
 
medical
 
images.
 
However,

effective
 
CNN
 
generally
 
requires
 
a
 
sufficiently
 
large
 
amount
 
of
 
labelled
 
data.
 
In
 
medical

labelled
 
data
 
can
 
be
 
difficult
 
because
 
image
 
annotation
 
often
 
requires
 
expert
 
knowledge
 
and
 
significant
 
time.
 
At
 
the
 
same

large
 
collections
 
of
 
unlabelled
 
medical
 
images
 
may
 
be
 
available.
 
This
 
creates
 
a
 
need
 
for
 
learning
 
methods
 
that
 
can
 
make
 
effective
 
use
 
of
 
both
 
labelled
 
and
 
unlabelled
 
data.
 
This
 
project
 
investigates
 
Self-Supervised
 
Learning
 
for
 
Medical
 
Image
 
Classification
 
Using
 
Labelled
 
and
 
Unlabelled
 
Data
.
 
The
 
main
 
objective
 
is
 
to
 
study
 
whether
 
useful
 
visual
 
representations
 
can
 
be
 
learned
 
from
 
unlabelled
 
medical
 
images
 
before
 
using
 
labelled
 
data
 
for
 
classification.
 
The
 
proposed
 
approach
 
uses
 
a
 
CNN-based
 
self-supervised
 
learning
 
framework
 
with
 
random
 
masking
.
 
During

an
 
unlabelled
 
medical
 
image
 
is
 
transformed
 
into
 
two
 
different
 
masked

Different

of

same

are
 
randomly

to

Both

through
 
the
 
same
 
CNN

with
 
shared
 
weights.
 
The

produces
 
feature
 
representations
 
for
 
the
 
two
 
views,
 
and
 
a
 
consistency
 
loss

to
 
encourage
 
their
 
representations
 
to
 
remain
 
similar.
 
The
 
difference
 
between

representations
 
provides
 
a
 
learning
 
signal
 
without
 
requiring
 
class
 
labels.
 
Through
 
this
 
process,
 
the
 
CNN
 
is
 
expected
 
to
 
learn
 
useful
 
visual
 
features
 
from
 
unlabelled
 
images.
 
After

pre-training,
 
the
 
learned
 
CNN
 
representation
 
is
 
used
 
for
 
supervised

with
 
labelled
 
medical
 
images.
 
A
 
classification
 
layer
 
is
 
added
 
to
 
perform
 
the
 
required
 
medical
 
image
 
classification
 
task.
 
The
 
performance
 
of
 
the
 
proposed
 
approach
 
will
 
be
 
compared
 
with
 
a
 
conventional
 
CNN
 
trained
 
using
 
labelled
 
data.
 
This
 
comparison
 
will
 
help
 
determine
 
whether
 
self-supervised
 
pre-training
 
provides
 
an
 
advantage
 
when
 
the
 
amount
 
of
 
labelled
 
data
 
is
 
limited.
 
The
 
experimental
 
study
 
will
 
use
 
suitable
 
datasets
 
from
 
MedMNIST
,
 
which
 
provides
 
standardized
 
medical
 
image
 
datasets
 
covering
 
different
 
modalities
 
and
 
classification
 
tasks.
 
The
 
project
 
will
 
investigate
 
the
 
effect
 
of
 
using
 
unlabelled
 
data
 
during
 
pre-training
 
and
 
will
 
evaluate
 
the
 
resulting
 
classification

using
 
appropriate
 
metrics
 
such
 
as
 
accuracy
 
(ACC)
 
and
 
area
 
under

ROC
 
curve
 
(AUC)
.
 
Additional

confusion
 
matrices
 
and
 
visual
 
explanation

Grad-CAM
,
 
where

to
 
understand
 
the
 
regions
 
influencing
 
model

The

will
 
also

the
 
contribution
 
of
 
important

the
 
proposed
 
approach,

random
 
masking
 
and

The

better
 
understanding
 
of
 
how
 
unlabelled
 
medical

can
 
contribute
 
to
 
representation

and
 
whether
 
this
 
can
 
reduce
 
dependence
 
on
 
large
 
amounts
 
of
 
labelled
 
data.
 
The
 
expected
 
outcome
 
of

project
 
is
 
a
 
practical
 
experimental
 
analysis
 
of
 
a
 
CNN-based
 
self-supervised
 
learning

for

It
